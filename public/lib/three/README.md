# three.js
JavaScript 三维场景渲染库

## 简要介绍
轻量易用的 WebGL 三维引擎，提供场景、相机、几何体、材质、光照、动画等完整 3D 渲染能力。

## 相关地址

- github地址：https://github.com/mrdoob/three.js
