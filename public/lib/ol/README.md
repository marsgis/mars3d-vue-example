# OpenLayers（ol）
开源二维 Web 地图库

## 简要介绍
功能完整的开源二维地图库，支持多源瓦片/矢量数据渲染与交互；`ol-cesium/` 子目录为 OpenLayers 与 Cesium 二三维联动控制器插件（本地为 muyao1987 fork 定制版，增加了 viewer 参数）。

## 相关地址
- 官网地址：https://openlayers.org
- github地址：https://github.com/openlayers/openlayers
- ol-cesium 插件地址：https://github.com/openlayers/ol-cesium（本地定制版：https://github.com/muyao1987/ol-cesium ）
