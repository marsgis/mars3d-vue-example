# video
流媒体视频播放组件合集

## 简要介绍
收录四个浏览器端流媒体播放组件：`flv/`（flv.js，Bilibili 开源的 FLV 播放）、`hls/`（hls.js，HLS/m3u8 协议播放）、`mpegts/`（mpegts.js，MPEG-TS 流播放）、`wfs/`（wfs.js，WebSocket 裸 H264 实时流播放）。hls、wfs 子目录内另有各自的使用说明 README。

## 相关地址
- flv.js 地址：https://github.com/bilibili/flv.js
- hls.js 地址：https://github.com/video-dev/hls.js
- mpegts.js 地址：https://github.com/xqq/mpegts.js
- wfs.js 地址：https://github.com/ChihChengYang/wfs.js

## 本地版本信息
见各源文件（压缩产物未统一内嵌版本号）
