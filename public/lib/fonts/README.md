# fonts
图标字体目录

## 简要介绍
收录项目用到的图标字体：`font-awesome/`（Font Awesome 4.7.0 经典图标字体，含 css 与字体文件）。

## 相关地址
- 官网地址：https://fontawesome.com
- github地址：https://github.com/FortAwesome/Font-Awesome

## 本地版本信息
Font Awesome 4.7.0

## 本地文件说明
含 `font-awesome/` 子目录（css、fonts、LICENSE、OFL.txt、README.md）。
目录内文件：`LICENSE`（Font Awesome 许可证全文）
