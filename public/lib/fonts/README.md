# fonts
图标字体合集目录

## 简要介绍
收录项目用到的图标字体：`font-awesome/`（Font Awesome 4.7.0 经典图标字体）、`marsgis/`（火星科技自有 iconfont 图标字体）、`web-icons/`（admui 后台 UI 配套图标字体，专有许可）。各子目录详细说明见其内 README。

## 相关地址
- 官网地址：https://fontawesome.com
- github地址：https://github.com/FortAwesome/Font-Awesome

## 本地版本信息
Font Awesome 4.7.0；marsgis / web-icons 版本见各子目录

## 本地文件说明
含 `font-awesome/`（css、fonts、LICENSE、OFL.txt、README.md）、`marsgis/`（iconfont 系列文件）、`web-icons/`（web-icons 系列文件、README.md）。
目录内文件：`LICENSE`（Font Awesome 许可证全文）
